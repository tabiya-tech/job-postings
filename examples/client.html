job-postings example client

Send job postings, then read them back. Open your browser's developer tools to see each request.

Connection

1. Send postings: POST /job-postings

The body is an array of postings. external_id (your own ID for the posting), title, description and country are required; the full list of fields is at /docs on the API. Send the same external_id again to update a posting.


  


  

    
2. List your postings: GET /job-postings

    
Newest first. Optional filters, as a query string: country, status,
      stage, external_id, updated_since, limit.

    
    

      
      
      
    

    

      
titlecountrystatusstageexternal_id

      
    

  


  

    
3. Read one posting: GET /job-postings/{id}

    
Click a posting in the list. processing shows each stage's status, attempts and last error.
